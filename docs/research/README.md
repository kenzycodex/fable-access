# Research and positioning

Background for product and engineering decisions: the fraud data, the market, the regulation, and how Fable explains itself. [PRODUCT-PRINCIPLES.md](../PRODUCT-PRINCIPLES.md) turns these into rules the code follows, with the status of each.

| File | What it is |
|---|---|
| [fraud-market-regulation-brief.md](fraud-market-regulation-brief.md) | The research brief (October 2026): NIBSS and INTERPOL fraud data, competitors, CBN and NDPA regulation, technical checks and claim verification, with a source link on each claim |
| [pitch-qa.md](pitch-qa.md) | 26 questions and answers checked against the brief, with notes on what not to say |
| [demo-walkthrough.md](demo-walkthrough.md) | A three-minute narrative and a three-minute sandbox walkthrough |

One file per purpose: when something changes, update the file in place rather than adding a new version beside it.

## Conventions

- **Figures** come from the brief. Anything it marks as unverified stays unverified until checked against the primary source.
- **No people or events:** nothing in this folder names team members or the events Fable has been presented at. Fable is described as a product.
